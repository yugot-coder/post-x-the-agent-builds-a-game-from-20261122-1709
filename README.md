NEON DRIFT — a tiny one-file HTML5 canvas game that an AI agent built from a single prompt, on camera: a neon spaceship dodges asteroids, collects stars, and the speed keeps ramping. The 48-second video shows the prompt arriving, the agent writing the game's real code, and the finished game running, and it ends with make.fun's referral end card. The video is posted natively on X; this repository hands in the post's address (`POST.json`), and `game.html` is the game itself — open it in any browser and press SPACE.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
